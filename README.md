# 👨‍💻 About Me

I’m **Rahul**, a **Full-Stack Software Developer** focused on building scalable, production-ready software across **web, backend, desktop, and mobile platforms**.

I work across the complete development lifecycle — from **UI architecture and backend APIs** to **databases, authentication, real-time systems, integrations, testing, cloud deployment, CI/CD, and application packaging**.

My core ecosystem includes **JavaScript, TypeScript, React, Next.js, Node.js, Express.js, PostgreSQL, Redis, C#/.NET, React Native, Electron, Docker, and cloud platforms**. I enjoy exploring new technologies and choosing the right tools based on the problem rather than being limited to a single stack.

I’m particularly interested in building **real-world business applications, scalable APIs, software integrations, automation systems, developer tools, and end-to-end products** with clean architecture and maintainable code.
